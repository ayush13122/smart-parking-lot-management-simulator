# CSM228 – Continuous Assessment Instructions

## Assessment Details

- **Course:** CSM228 – Data Structures
- **Assessment:** Continuous Assessment (CA)
- **Mode:** Online
- **Type:** Individual project-based assessment
- **Total Marks:** 30
- **Schedule:** Week 12/13

## Evaluation Components

| Component | Marks |
|---|---:|
| Project Demonstration | 10 |
| Project Presentation | 10 |
| Viva | 10 |
| **Total** | **30** |

## Instructions for Students

1. Each student must independently develop and present a project demonstrating the application of data structures covered in the course.
2. Students must be ready to demonstrate project functionality and explain its implementation.
3. The presentation should cover the problem statement, objectives, data structures used, implementation, and working methodology.
4. Students should be prepared to answer viva questions related to the project, algorithms, and concepts used.
5. Keep the laptop/device ready with the project and required software installed.
6. Ensure the device is fully charged and the project is ready for demonstration.

The date, time, and any additional assessment instructions are to be communicated separately by the course team.
