# CSM228 – Data Structures Syllabus Outline

## Course Outcomes

- **CO1:** Describe the process to find efficiency of algorithms using asymptotic notations.
- **CO2:** Illustrate the importance of Queue in context of problems solving.
- **CO3:** Differentiate the HashTable and HashMap in context of writing efficient program.
- **CO4:** Identify the appropriateness of HashSet and tree in problem solving.
- **CO5:** Analyze the effectiveness of Priority queue and Heap Data Structures.
- **CO6:** Use Graph and various techniques in real-world problem solving.

## Units

### Unit I
- Introduction: Basic Data Structures, Basic Concepts and Notations, Complexity analysis, time-space trade-off, Omega, Theta, and Big O notation.
- Stacks: Introduction, implementation, parenthesis matching, and file versioning system.

### Unit II
- Queues: Introduction, implement a stack using one queue, implement a stack using two queues, ticket booking system using queues, palindromic string problem, duplicate parenthesis problem, reversing a stack problem, and Kth largest element problem.

### Unit III
- HashTables: Design and performance analysis, hash functions and hashing, collisions, checking hash function quality, dictionary (phone book) implementation using a hash table.
- HashMaps: Introduction, symmetric pairs, asymmetric pairs, and first unique character problems.

### Unit IV
- HashSets: Introduction, array of contiguous integers, pair with a given sum, itinerary from all tickets, and match locks and keys.
- Binary Trees: Linear vs non-linear data structures, types and representations, properties, DFS and BFS traversal, runway reservation, mirroring a tree, and spiral-order traversal.
- Binary Search Trees: Introduction, search, insertion, deletion, lowest common ancestor, balanced BSTs, and title problem.

### Unit V
- Priority Queues: Introduction, ADT, implementation using linked list and array list.
- Heaps: Introduction, basic operations, sorting, merge k sorted linked-list problem, and median of stream of integers.

### Unit VI
- Graphs and Graph Algorithms: Adjacency matrix, real-life applications, DFS, BFS, adjacency list, edge list, and Dijkstra's algorithm.

## Project Alignment

The Smart Parking Lot Management Simulator primarily demonstrates the **Queue, HashMap, and HashSet** topics, along with basic time-complexity analysis.
